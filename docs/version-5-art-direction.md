# DekolonizArt Version 5 — Archive / Signal

## Visual philosophy

Version 5 treats the website as a living performance archive: a dark stage, a paper score, and a broadcast signal. Images are evidence, dates are cues, and language is set like a poster in rehearsal. The identity is rooted in the DekolonizArt palette, but the page is not a stack of branded panels.

## Composition and typography

The desktop composition uses a narrow command rail and an expansive field. Large `movement` headlines are cropped, overprinted, and allowed to cross section boundaries. `Source Sans Pro` carries the reading layer, metadata, navigation, and long-form text. A 12-column grid is intentionally interrupted by a vertical date spine and horizontal “tape” bands.

## Image language

Photography is treated as documentary material: hard crops, poster windows, transparent overlays, and image strips. No generic image card is used. Each content type gets its own editorial grammar: event rows are a calendar ledger, services are chapters, artists are a magazine index, and the contact page is a coordinate sheet.

## Navigation and motion

The header is a compact command bar with a menu that opens as an index drawer; it is not a conventional horizontal menu. Motion is a restrained signal: reveal lines, poster lifts, a slow image drift, and a horizontal text ticker. All animation yields to `prefers-reduced-motion`.

## Responsive transformation

On small screens the command rail becomes a top strip, the index drawer becomes a full-height sheet, and the wide compositions become a vertical reading sequence. Event dates keep their spine, the hero keeps its overprinted type, and images become full-bleed evidence rather than shrinking desktop columns.
